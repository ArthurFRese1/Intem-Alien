ALIEN RPG — BANCO DE ITENS
==========================

Site independente de consulta de itens de ALIEN RPG (HTML, CSS, JavaScript e JSON).
Não depende de outros sites nem de APIs externas.

COMO EXECUTAR
-------------
O site lê o arquivo dados/itens.json, então precisa rodar por um servidor local
(abrir o index.html com duplo clique NÃO funciona em vários navegadores).

1. Instale o Visual Studio Code (https://code.visualstudio.com).
2. Dentro do VS Code, abra a extensão "Live Server" (Ritwick Dey) e instale.
3. Use "Arquivo > Abrir Pasta..." e escolha a pasta AlienItens.
4. Clique com o botão direito em index.html e escolha "Open with Live Server".
5. O navegador abrirá o catálogo (normalmente em http://127.0.0.1:5500).

Alternativa sem VS Code (precisa de Python): na pasta AlienItens, execute
  python -m http.server 8000
e abra http://localhost:8000 no navegador.

PUBLICAR NO GITHUB PAGES (GRATUITO)
-----------------------------------
1. Crie uma conta em https://github.com (se ainda não tiver).
2. Clique em "New repository". Nome sugerido: AlienItens. Deixe como Public
   (o plano gratuito só publica repositórios públicos).
3. Na página do repositório, clique em "uploading an existing file" e envie
   o CONTEÚDO da pasta AlienItens (index.html, style.css, script.js,
   .nojekyll, LEIA-ME.txt, VERSAO.txt e a pasta dados com itens.json).
   index.html precisa ficar na raiz do repositório, não dentro de outra pasta.
   Clique em "Commit changes".
4. Vá em Settings > Pages. Em "Build and deployment", escolha
   Source: "Deploy from a branch", Branch: main, pasta: / (root). Salve.
5. Aguarde 1 a 3 minutos. O endereço será:
   https://SEU-USUARIO.github.io/AlienItens/

Observações:
- Não é preciso instalar nada nem usar Live Server: o GitHub Pages já é um servidor.
- O arquivo .nojekyll evita que o GitHub processe o site com Jekyll.
- Para atualizar o site, envie os arquivos alterados para o repositório.
- Os itens personalizados ficam salvos no navegador de cada visitante
  (LocalStorage); não são enviados para o GitHub nem compartilhados.
- Se o catálogo não carregar, apague o cache do navegador (Ctrl+F5) e confira
  se a pasta dados/itens.json foi enviada.

ITENS PERSONALIZADOS
--------------------
Use o botão "+ Adicionar item". Os itens ficam no LocalStorage do navegador,
separados do catálogo original, e continuam disponíveis ao reabrir o navegador
(a menos que os dados do site sejam apagados). Para excluir, abra o item e use
"Excluir item" (há confirmação). Os dados originais nunca são apagados.
Observação: o LocalStorage é por navegador e por endereço; mudar de navegador
ou de porta do Live Server mostra uma lista de personalizados diferente.

COMO ADICIONAR ITENS AO CATÁLOGO ORIGINAL
-----------------------------------------
Edite dados/itens.json e acrescente objetos na lista "itens". Campos:

  id           Identificador único, sem espaços (ex.: "faca-de-combate")
  nome         Nome do item
  categoria    Ex.: Armas, Proteção, Tecnologia, Medicina, Suprimentos...
  tipo         Subtipo (ex.: Pistola, Traje, Fármaco)
  raridade     Deixe "" se o livro não informar. O filtro de raridade só
               aparece quando algum item tem esse campo preenchido.
  fabricante   Deixe "" se não informado
  descricao    Resumo próprio (não copie trechos do livro)
  atributos    Pares "Rótulo": "Valor" exibidos nos detalhes, na ordem escrita
  tags         Lista de palavras-chave para a pesquisa
  fonte        Ex.: "Livro Básico, cap. 6, p. 120"
  observacao   (opcional) divergências ou avisos sobre os dados

As categorias, tipos e filtros se atualizam sozinhos a partir do JSON.
Depois de editar, valide o JSON (vírgulas e aspas) e recarregue a página.

SOBRE O CONTEÚDO
----------------
- Os valores de armas, trajes, veículos etc. seguem as tabelas do capítulo 6 do
  Livro Básico em português. Em alguns itens as ilustrações do livro mostram
  números diferentes das tabelas; isso está indicado no campo "Observação".
- As descrições são resumos próprios, não reproduzem o texto do livro.
- Campos sem informação ficam vazios; nada foi inventado.
- Não foram incluídas linhas que não são objetos (ex.: "Ataque Desarmado").
- "Pistola de Parafuso Watatsumi DV-303" e "Maçarico Mecânico de Corte" aparecem
  uma única vez (em Armas); o uso como ferramenta consta nos detalhes.
- O catálogo NÃO está completo: esta versão cobre o capítulo 6 do Livro Básico.
