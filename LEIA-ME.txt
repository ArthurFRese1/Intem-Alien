ALIEN RPG — BANCO DE ITENS E BANCO DE ALIENS
Versão local, sem login, sem contas e sem Supabase.

COMO USAR
1. Extraia a pasta AlienItens.
2. Abra index.html em um navegador para testar. Para publicar, envie os arquivos mantendo a estrutura de pastas para o GitHub Pages.
3. Use as duas abas superiores para alternar entre Itens e Aliens.
4. Os botões de adicionar abrem formulários. Os registros personalizados são guardados no armazenamento local do navegador.

ARMAZENAMENTO
- Itens personalizados, aliens personalizados, favoritos, coleções e preferência de visualização usam LocalStorage.
- Imagens dos aliens personalizados são armazenadas como dados locais no navegador. Para evitar exceder o limite do navegador, o formulário aceita imagens de até 1,5 MB.
- Os dados não são sincronizados entre dispositivos. Limpar os dados do navegador pode apagá-los. Faça cópias de segurança se forem importantes.
- O catálogo oficial fica nos arquivos dados/itens.json e dados/aliens.json.

ESTRUTURA
index.html          Interface e modais
style.css           Identidade visual e layout responsivo
script.js           Pesquisa, filtros, cadastros, favoritos e coleções
dados/itens.json    Catálogo de itens
dados/aliens.json   Catálogo de criaturas

OBSERVAÇÕES
- Não há dependências externas, autenticação ou serviços em nuvem.
- O site é um projeto independente de fãs, não oficial.
